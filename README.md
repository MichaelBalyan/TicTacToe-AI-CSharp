# 🎮 Tic-Tac-Toe (C#)

A C# implementation of the classic Tic-Tac-Toe game featuring a strategic computer opponent, built with a strong focus on clean architecture, Object-Oriented Programming, and maintainable code. The project demonstrates algorithm design, game state management, and decision-making logic.

## ✨ Features

- **Strategic Opponent** – Evaluates the board to make offensive and defensive moves instead of selecting random positions.
- **Early Draw Detection** – Predicts inevitable draw scenarios before the board is completely filled, avoiding unnecessary gameplay.
- **Object-Oriented Design** – Structured using OOP principles with clear separation of responsibilities.
- **Game State Management** – Efficiently manages player turns, win conditions, and draw detection.
- **Clean & Maintainable Code** – Written with readability, extensibility, and long-term maintainability in mind.

## 🧠 Decision-Making Logic

The computer opponent analyzes the current board state to:

- Detect immediate winning opportunities.
- Block the opponent's winning moves.
- Predict unavoidable draw scenarios.
- Select the most strategic available move.

## 🛠 Technologies

- C#
- Object-Oriented Programming (OOP)
- Algorithm Design
- Game State Management
- Clean Code Principles

## 📌 Purpose

This project was developed to strengthen algorithmic thinking, Object-Oriented Programming skills, and game logic implementation by building a complete Tic-Tac-Toe game with a strategic computer opponent.
